# 🏥 Healthcare Data Analysis

## 📌 Project Overview

This project is a healthcare data analysis project using **Python, PostgreSQL, and SQL**.

The main purpose of this project is to explore healthcare data and find useful insights related to patients, hospitals, medical conditions, admissions, billing, insurance providers, doctors, and length of stay.

The project was completed in two main stages:

**Python → SQL/PostgreSQL**

First, Python was used for **data exploration, cleaning, preparation, and Exploratory Data Analysis (EDA)**.

After preparing the data, it was loaded into **PostgreSQL**, where SQL queries were used to perform further analysis and answer different business questions.

---

# 🎯 Project Objectives

The main objectives of this project are:

- Understand the healthcare dataset
- Explore the data using Python
- Clean and prepare the dataset
- Perform Exploratory Data Analysis (EDA)
- Understand patient and hospital patterns
- Analyze medical conditions
- Analyze billing and healthcare revenue
- Analyze insurance providers
- Analyze doctors and hospitals
- Analyze patient admissions over time
- Perform business-oriented analysis using SQL
- Use advanced SQL concepts such as CTEs and Window Functions
